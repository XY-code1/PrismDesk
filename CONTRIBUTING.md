# Contributing

1. Open an issue with the client name, exact version, Windows version, and redacted diagnostic result.
2. Create a focused branch; do not commit client binaries, user backgrounds, logs, credentials, chat data, or personal absolute paths.
3. Run `npm run check && npm test && npm run build`.
4. Adapter changes require a positive real-client check, a negative structure check, idempotency, and restoration evidence.

By contributing, you license original contributions under MIT. Do not copy third-party branding, artwork, or code without recording compatible provenance and license terms.
